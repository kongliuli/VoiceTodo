# 1330 · 语音训练流程更新

来源：用户在绘制修订稿期间明确提出“模板可以不需要；语音识别训练组以后自动创建和开始；可配置5秒/3秒倒数并给出下一步指示”。本更新替代本组文档及旧总纲中的D3常规确认步骤，D4按本次指示改为去除模板入口。尚未修改应用代码。

- 明确且有效的训练指令：识别 → 校验 → 自动创建并开始，不弹常规确认页。
- 歧义、缺关键时长/轮数、无效参数：先澄清，不猜测后启动。重复识别结果不能重复创建。
- 已有训练运行：不静默覆盖；提示当前训练，并要求明确结束/替换意图。多计时仍待实施。
- 语音倒数按每个运动/休息阶段结束前最后5秒或3秒理解，可关闭；不作为启动前等待时长。
- 阶段切换播报下一步动作、时长与轮次；最终阶段结束播报训练完成，不再指示不存在的下一步。
- 短于倒数窗口的阶段只播报实际剩余秒数；暂停停止报数，恢复不重复已过数字；后台恢复不补播过时倒数。
- 播报调度以真实计时为准，不等待TTS播完再切阶段；避免倒数与下一步口令重叠。
- 倒数设置默认图示3秒；5秒/3秒/关闭为选项。配置变更默认用于下次训练。
- 自动开始结果提供“暂停”和“识别有误，停止并修改”；手动停止记录中断，不伪造完成。
