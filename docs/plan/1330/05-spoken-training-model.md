# 1330 · 口述训练计划与可选模板

本文件按用户最新澄清更新，优先于04更新中“去除模板”的解读。用户目标是口述任意动作与组间规则直接创建训练；模板可选，可套用修改。自动创建并开始仍沿用此前明确要求。

## 统一产品模型

语音、文字、手动编辑、可选模板都产生同一种训练计划，不以是否命中模板判断能否创建。动作名称为用户文本，例如深蹲、平板支撑、拉伸；不强制内置动作分类，不凭名称推断医学或运动建议。

计划包含：动作名称、组数、每组运动时长、组间休息时长、是否末组休息、结束前倒数窗口（5秒/3秒/关闭）、阶段指示开关。运行实例引用启动时的计划快照，记录当前组/阶段、暂停、实际时间与结果。修改模板不会修改已开始的训练。

示例：“深蹲10组，每组持续5秒钟，休息10秒” → 深蹲，10组，运动5秒，组间休息10秒。建议默认末组无休息，总时长10×5+9×10=140秒，即02:20；若选择包含末组休息则02:30。这是明确可见的产品默认建议，不是从原话推断出的事实。

## 三种创建入口

1. 口述创建（主入口）：识别文本 → 提取动作/组数/运动/休息 → 校验 → 立即创建运行实例并开始，展示简短“已开始”反馈及暂停/停止纠错入口，不强制查看一整页确认。
2. 模板套用（辅助）：选择模板 → 复制为本次计划 → 语音或字段修改 → 用户点击开始。自动开始不应用于仅浏览模板或编辑参数。
3. 训练历史复用：从完整计划快照复制，不仅取累计时长；选择再次开始才创建新运行。

“保存成我的模板”为训练详情/结束后的次级动作，不强迫每次临时训练命名存模板。模板入口保留，但低于“说出训练”。

## 口述理解边界

- 支持同义词：组/轮，每组/每轮，持续/做，组间休息/歇。默认单位只在用户设置或显式澄清后应用，不猜测“5”是秒还是分钟。
- “10次”是重复次数，不是“10组”，不能静默改成计时组；未支持计次数训练时说明并询问按时长安排。
- 缺组数、缺时长、多个可能动作、单位歧义：只追问缺失项，已识别字段保留。不要要求重复整句话。
- 否定/修正语句“不是10组，是8组”应更新草稿；已有运行时不能重新解析为第二个新训练。语音识别最终结果需去重，临时结果不执行。
- 明确的创建指令自动开始；描述示例、询问、模板浏览与改设置不启动。后端执行前区分意图，不根据出现数字就启动。
- “深蹲后做平板支撑”属于动作序列扩展。第一阶段先做好单动作多组；不能丢掉后半句并声称已完整安排。后续可扩展动作段列表，共用同一执行模型。
- 已有训练运行：保留当前训练，不直接覆盖；请求用户明确替换/结束。多活动训练可单独扩展。

## 报数与下一步

以各阶段剩余时间触发5秒/3秒倒数，不是开始前准备延迟。第一组可简短播报“第1组，深蹲”；运动结束播报“休息10秒”；休息结束播报“第2组，深蹲”；最后一组结束播报“训练完成”。屏幕始终可见下一步。

短阶段不要读长句覆盖全部5秒。使用短提示音/短口令；倒数与阶段提示进入同一音频队列，过期提示丢弃，不能播完一长句才切阶段。暂停取消待播，恢复按真实剩余时间继续，后台唤醒不补播错过的倒数。阶段短于窗口时只报实际剩余秒数。

首组自动开始可能发生在播报尚未结束时，因此“报数语音播放时间不延长计时”需明确验收；如后续增加准备时长，应为独立设置，不能与末秒倒数混用。
