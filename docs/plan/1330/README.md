## 不变的产品约束

1. **D1：手动开启会话，无空闲超时，手动结束。** 系统强制中断必须可见，不承诺进程永远存活；“取消本句”和“结束会话”是两个动作。
2. **D2：语音创建的健身计时全部留痕，进日历、可改名。** 当前已有结束记录，仍需补活动状态与可靠恢复。
3. **D3：先确认再跑。** 提案采用一次明确的“确认并开始”；编辑计划不启动，取消不启动，不再使用两次含糊确认。
4. **D4：旧预设入口取舍仍待定。** 保留快捷入口，与编辑器共用模板数据，不主动删除。
5. 任务、计时、语音会话是不同实体；结束任一实体不自动结束另一个。
6. 底部保持“今天 / 清单 / 计时”；日历归入清单浏览方式。新页面优先作为现有入口的子页或状态层。
7. UI 展示“已保存”不等于“提醒已安排”。权限、调度、数据写入各自有真实结果。
