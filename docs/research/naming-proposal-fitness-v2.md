# 命名提案 · 健身 / 间歇方向 V2（去军事化）

> 时间：2026-09-11
> 修订原因：**V1 的军事意象与目标人群不符**——面向的是健身人群，且其中女性占比不低。
> 约束不变：中文取自古诗词 + 英文意译；主线 = **规划 · 掌控 · 沟通**。

---

## 0. V1 为什么被否（记下来，避免重犯）

| V1 候选 | 问题 |
|---|---|
| 鼓角 | 出自「五更鼓角声**悲壮**」——军营、边塞、悲慨 |
| 击鼓 | 《诗经·击鼓》是**战歌**，`用兵`＝用兵打仗 |
| 点兵 | 「沙场秋点兵」——沙场、点兵，纯军事 |
| 金柝 | 《木兰诗》「朔气传金柝」——军中打更 |

**共同毛病**：它们讲的是「**服从命令**」，不是「**锻炼身体**」。军事语汇的核心是上下级、是号令、是牺牲；健身语汇的核心是**自我、节律、坚持、变好**。两者不是一回事，硬套会显得别扭——对女性用户尤其如此（军事/悲壮/阳刚的默认气质）。

**保留的只有一个结构性洞察**：本 App 的「沟通」本质上是**用声音给出节拍**，让你不用看屏幕就能跟着动。这个洞察不带军事色彩，可以继续用。

## 1. 换一套意象：节律 · 相伴 · 自我掌控

| 旧（军事，弃用） | 新（改用） |
|---|---|
| 击鼓进军 | 踩着拍子起舞 |
| 沙场点兵 | 从容地安排好自己的训练 |
| 号令传令 | 一呼一应，像有人陪着你练 |
| 军中报更 | 光阴里的一小段、一小段 |
| 悲壮、牺牲 | 轻盈、坚持、变得更好 |

新意象的来源也整体换掉：**汉乐府、诗经、楚辞九歌、宋词**——这些是歌唱、舞蹈、思念、山水的世界，不是军营。而且**宋词与乐府里女性作者与女性视角极多**（李清照、朱淑真），天然更贴合客群。

## 3. 逐项说明

### A · 应律 / Attune ★推荐

- **原句**：《楚辞·九歌·东君》「**应律兮合节**，灵之来兮蔽日。」
- **为什么是它**：这一句直接就是你要的三个词——`律`（音律、节律）是**掌控**，`节`（节拍）是**规划**（分拍、分段），`应`是**沟通**（响应、应答）。四字里三个字各管一件事，**没有任何一个候选能这么整齐地对上**。
- **气质对**：《九歌》是祭神的乐歌，浪漫瑰丽，是**音乐与舞蹈**的世界，跟军营无关。
- **英文 `Attune`**：意为「**使合拍、调准音、与之协调**」（*attuned to*）。含义干净，且带"身处其中、彼此协调"的暖意，不是命令式的。
- **风险**：`应律` 对普通用户略生僻；`律` 可能被联想到「法律」。需要靠副标题与商店描述托底。**这是它唯一的短板——如果你觉得太"文"，看 B。**

### B · 踏歌 / Stride

- **原句**：李白《赠汪伦》「李白乘舟将欲行，忽闻岸上**踏歌**声。」
- **为什么好**：`踏歌` 是一种**以脚踏地为节拍、边走边唱**的民间活动——字面就是「运动 + 声音」。它同时说完了产品的两条腿：**你在动（踏），它给节拍（歌）**。
- **气质**：有活力、有画面、不冷硬，男女都不会被排斥。
- **风险**：① 因《赠汪伦》带**送别**色彩；② 容易被读成民俗/日式舞蹈。**它不覆盖「规划」**。

### C · 起舞 / Rise

- **原句**：苏轼《水调歌头》「**起舞**弄清影，何似在人间。」（另参成语「闻鸡**起舞**」）
- **为什么好**：双出处——宋词名句（美、人人会背）+ 闻鸡起舞（**听到鸡叫就起身练功**，这是现成的"自律锻炼"叙事）。`起舞` 讲的是**你自己起身开始**，与「自我掌控」同向。
- **气质**：优雅 + 有劲儿，是最"中性"的一个。
- **风险**：偏"舞蹈"，与"间歇训练"的工具感有些距离；不覆盖「规划·沟通」。

### D · 友声 / Kindred

- **原句**：《诗经·小雅·伐木》「嘤其鸣矣，求其**友声**。」
- **为什么好**：一句话把「沟通」说尽——**我出声，是为了找到回应**。用在产品上就是"你一喊，它应你"，比"号令"暖得多，也天然适合"陪着练"的定位。
- **英文 `Kindred`**：意为同类、意气相投的人（*kindred spirit*）。不是"下属/上级"，而是"同路人"。
- **风险**：不覆盖「规划·掌控」；且对"计时"这件事没有指向。

### E · 涟漪 / Ripple

- **原句**：《诗经·魏风·伐檀》「河水清且**涟**猗。」（`涟漪` 即由此而来）
- **为什么好**：最轻盈、最女性友好、最有画面感的一个——**一圈一圈推开**，可以讲成"每一组都在累积"。
- **风险**：含义离"健身/计时"最远，几乎是纯气质名；`Ripple` 又是加密货币 XRP 的公司名，英文撞车风险偏高。

### F · 作息 / Cycle

- **原句**：《击壤歌》「日出而作，日入而息。」（古歌谣）
- **为什么好**：`作`（动）+ `息`（歇）——**这直接就是间歇训练的定义**。规划与掌控都覆盖到了，且极其生活化、人人秒懂。
- **风险**：`作息` 在现代汉语里主要指"作息时间/日常安排"，作商标**显著性弱、注册难**；而且太普通，做不成品牌。**建议只当产品概念词（work/rest），不建议当 App 名。**

## 4. 推荐

**首选：A · 应律 / Attune**

理由只有一条但足够硬：**它是唯一一个把「规划·掌控·沟通」三根柱子同时接上的候选**——`律`=节律（掌控）、`节`=分拍（规划）、`应`=应答（沟通），而这三个字出自同一句楚辞，不是拼凑的。加上《九歌》本身是乐舞的世界，气质与健身/女性客群没有冲突。

**按你的侧重挑：**

| 你更看重 | 选它 | 英文 | 代价 |
|---|---|---|---|
| **三根柱子都要** | 应律 | Attune | 略生僻，需副标题托底 |
| **好懂 + 有画面**（运动+声音） | 踏歌 | Stride | 不覆盖「规划」 |
| **优雅 + 中性 + 自律叙事** | 起舞 | Rise | 偏舞蹈，不覆盖规划/沟通 |
| **暖、像陪着练** | 友声 | Kindred | 不覆盖规划/掌控 |
| **最轻盈、最女性友好** | 涟漪 | Ripple | 离功能最远，英文撞车 |
| 产品概念词（不作 App 名） | 作息 | Cycle | 商标显著性弱 |
