## 0. 从 12 次失败里提炼出的规则

前两轮一共验了 12 个候选，只活下来 3 个（潮有信、合节、一弹指；后两个待正式检索）。把失败样本放在一起看，规则很清楚：

### 要（三要）

| | 规则 | 正例 |
|---|---|---|
| **1** | **有典**：能在古代文献里找到书证（不是现编的） | 合节——《楚辞·九歌·东君》 |
| **2** | **低频**：不是成语、不是名句、不是日常高频词 | 合节（只在《楚辞》《墨子》出现） |
| **3** | **词义直译即产品**：字面翻译过来就是产品本身 | 合节 → rhythm / harmony |

### 不要（三不要）

| | 禁忌 | 反例（全被占） |
|---|---|---|
| **1** | 不要**成语** | 天行健（国家体育总局同名健身平台） |
| **2** | 不要**名句** | 知时节（杜甫）、一炷香、一盏茶 全是名句 → 全被占 |
| **3** | 不要**"一眼就懂"的直觉创意** | "香燃尽=倒计时"→《燃一炷香》；"天行健=不停运动"→体育总局 |

**第三条最重要**：创意越自然，全国同时想到的团队越多，撞车概率越高。

## 1. 本轮的坏消息：连冷门《诗经》词都被占了

我原以为「嘤鸣」（出自《诗经·小雅·伐木》"嘤其鸣矣，求其友声"）够冷门。实测：

| 商标 | 类别 | 状态 |
|---|---|---|
| 嘤鸣健康 | 5 类 医药 / 30 类 方便食品 | 已注册（**嘤鸣(杭州)健康科技有限公司**，2024-11-07 起） |
| 青鸟嘤鸣 | **42 类 设计研究（含"计算机软件设计"）** | 已注册（中道弘毅(杭州)教育科技，2026-04-21 起） |
| 嘤其鸣 | 15 类 乐器 | 已注册 |

**结论：中国存在一整条"古诗文商标"注册产业链，而它们优先落地的正是健康类（5/30 类）和软件类（9/42 类）——恰好是我们的类别。**

这意味着：**"有典 + 低频 + 空闲"的二字/三字古词，池子已经基本抽干。** 不是我们运气差，是池子里真的没水了。

## 2. 五层词源扫描（新候选池）

下面按词源分层，每层给足候选。状态标记：🔴 已验证被占｜🟡 曾检索未命中（待正式检索）｜⬜ 未查。

### 层 1 · 音乐 / 节律书证词（对应 rhythm · cadence · beat）

| 词 | 出处 | 义 | 覆盖 | 状态 |
|---|---|---|---|---|
| **合节** | 《楚辞·九歌·东君》「应律兮合节」；《墨子·节葬》 | 合于节奏；思想行为一致 | 规划·掌控·沟通 | 🟡 ★首选 |
| **中节** | 《礼记·中庸》「发而皆中节谓之和」；《庄子·养生主》「乃中经首之会」 | 恰到节度 | 掌控·规划 | 🟡（有"中节认证"公司，未见同名 App） |
| **倚声** | 词学术语「倚声填词」 | 依着曲调/节拍来 | 沟通·节律 | 🟡 检索被"声音商标"污染，未查实 |
| **应拍** | 「应拍而舞」 | 跟着拍子 | 沟通·节律 | ⬜ |
| **协律** | 汉「协律都尉」（李延年） | 调谐音律 | 沟通·掌控 | ⬜ |
| **按节** | 「按节而歌」 | 依节拍而行 | 规划 | ⬜ |

**「倚声」值得单独说**：它是词学术语，意思是"依着曲调填词"——**"依着声音"这个字面，恰好就是本产品的机制（用声音给节拍）**。冷僻度极高。是层 1 里最贴题的一个。

### 层 2 · 时间 / 守时（对应 planning · punctuality）

| 词 | 出处 | 义 | 状态 |

| **刻漏** | 古代计时器 | 计时 | ⬜（"漏"字偏冷） |
| **寸阴** | 「寸阴是竞」（《晋书》） | 时间可贵 | ⬜ |

**「花信」的额外价值**：它的含义（花开守时而来）天然贴合"节律 + 守信"，而且**二十四番花信风**本身就是一个"分轮次、每轮一花"的系统——**结构上和间歇训练的"分轮次"同构**。同时是最女性友好的一个（花、候、风）。代价：花信风已多类被占，「花信」二字待查。

| 词 | 出处 | 义 | 状态 |

## 3. 唯一有真实空位的一层：生造组合

既然"有典的词"已被产业链扫空，那**只剩"有典的骨架 + 无人注册的整词"**这条路。

关键手法：**用词体名做后缀**。「令」「引」「近」「慢」本是词体/曲体名称（十六字令、清江引、好事近、声声慢）。加在书上词后面，既有古意，又是**全新整词，无人在商标局排队**。

| 生造候选 | 骨架出处 | 读感 | 备注 |
|---|---|---|---|
| **合节令** | 合节（《九歌·东君》）+ 令 | 稳定、有古意 | ★推荐 |
| **倚声令** | 倚声（词学术语）+ 令 | 音乐性强 | ★推荐 |
| **花信引** | 花信风 + 引 | 轻盈、女性友好 | ★推荐 |
| **中节引** | 中节（《礼记·中庸》）+ 引 | 文气 | 读音歧义仍在 |
| **应律行** | 应律（《九歌·东君》）+ 行 | 行动感 | 「应律」45 类已注册，需避让 |
| **潮有信** | 李益《江南曲》（半生造，原句词） | 自然、水 | **备选（保留）** |
| **一炷时** | 一炷香（古计时单位）改写 | 温柔 | 「一炷香」已占，此词绕开 |

生造词的优势有三：**① 商标显著性天然高；② 无人抢注；③ 可人为把三根柱子塞进同一个词**。代价：需要靠产品和文案把它讲出来，不能自带流量。

## 4. 英文意译候选（低频优先，全部待检索）

上一轮已确认：`Attune` / `Stride` / `Rise` / `Kindred` / `Ripple` / `Cycle` 全被健身/健康类 App 占用。所以英文必须走**低频词**或**生造词**。

| 中文 | 英文候选 | 说明 |
|---|---|---|
| 合节 | **`Accord`** | 对应汉典第二义"相互一致 / harmony"；也含"和音"。需查第 9/42 类 |
| 合节 / 花信 | `Cadence` | 音乐义"节奏"；跑步行业术语"步频"。**但 Cadence 是大型 EDA 公司（楷登电子）**，慎用 |
| 中节 | `Measure` | 双关：节拍 + 尺度。常见词，需查 |
| 倚声 | **`Lilt`** | 意为"轻快有节奏的歌唱/律动"。单音节、低频、女性友好 ★ |
| 唱和 / 沟通 | **`Antiphony`** | 音乐术语：**一唱一和的应答式歌唱**。极低频，语义精准到惊人 ★ |
| 有常 | `Abide` | 古语感，兼"持守"与"持续" |
| 时习 | `Rehearse` | "反复演练"，健身与练习通用 |
| 花信 | `Flowerwind` / `Petaltide` | 生造，对应"花信风" |

**`Lilt` 和 `Antiphony` 是这轮英文侧的真正发现**：前者把"轻快的节律"一个词说尽，后者把"一唱一和"精确对应成英文的音乐术语——两者都不是健身赛道的高频词，所以躲得开上一轮那个"高频=被占"的规律。

## 6. 建议与下一步

**本轮新增的最优三个**：`倚声`（机制本身）、`时习`（训练的古典定义）、`有常`（作息规律）。它们都属于"有典 + 低频 + 词义即产品"，且都不是名句、不是成语。

**若要一个"最不像别人"的**：走**生造层**，**合节令**（骨架出自《九歌·东君》，整词无人在商标局排队）。

**潮有信保留为备选**，不再推进核查，除非前面几个都出问题。

**下一步（等你选）：**
1. 从上面挑 2–3 个，我去做正式可用性核查（中国商标网第 9/41/42 类 + 三大商店重名 + 域名）；
