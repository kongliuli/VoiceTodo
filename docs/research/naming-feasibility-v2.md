## 2. 关键发现（比"名字被占"更重要）

### 2.1 英文一侧的失效是**系统性**的，不是运气差

看这 6 个英文词的共同点：它们都是**健康 / 健身 / 节律赛道的高频、有力、单音节或双音节实词**——`Attune`（协调）、`Stride`（步伐）、`Rise`（起身）、`Kindred`（同类）、`Ripple`（涟漪）、`Cycle`（周期）。

**规律：越是一个"意译得漂亮"的英文单字，越早就被别人注册成健身 App。**

这不是巧合。这些词正是全球健身 App 起名时最先被想到的一批词，所以被扫得最干净。**「中文取自古诗词 + 英文意译」这条路线，问题不在中文一侧（古诗里的词够多），而在英文一侧：意译得住的那个字，基本已经没了。**

对照上一版通用提案 `naming-proposal.md` 的词（`Kairos` / `Windfall` / `Linger` / `Aside`）——它们占用率低得多，恰恰因为**词频低**。所以转向方向很清楚：**保留"意译"，但要主动把意译词的词频降下来。**

### 2.2 三个意外的市场信号

| 发现 | 含义 |
|---|---|
| *Attune: Hormone Fitness*——女性激素感知健身，含 PCOS / 围绝经期 / GLP-1 专项 | 我们判断的「女性 + 健身」细分**已经有人在做了**，且已上架（2026-04）。定位判断被验证，但也说明这条道开始有人 |
| 「踏歌」是**舞蹈 + 健身 + 音乐**安卓应用，「涟漪」是**助眠 + 冥想 + 呼吸训练**应用 | 我们选的意象（乐舞 / 轻盈）确实精准命中该赛道的气质——**这反过来说明这类词天然扎堆，必须往更冷僻处去** |
| 杭州友声科技（新三板）自称拥有 50+ 商标 | 中文双字词被"专利/商标密集型企业"批量圈占，两个字的常用古词几乎无空位 |

### 2.3 中文一侧：双字古词基本饱和

4/6 被占，剩下 2 个一个是待查（起舞）、一个是通用词（作息）。**两个字的、出自名句的、好懂的词，已经没有位置了。** 可行方向只剩：

- 三字 / 四字词组（如直接取「应律合节」「清且涟猗」这类整句片段）
- 冷门篇目里的字（避开《水调歌头》《赠汪伦》这种人人会背的）
- 自造复合词（如「律·节」「作息律」）

## 3. 下一步：五条可选策略（需拍板）

| # | 策略 | 英文示例方向 | 优点 | 代价 |
|---|---|---|---|---|
| **S1** | **英文＝中文名的拼音/罗马化** | `Yinglü` / `Qiwu` / `Hesheng` | 碰撞概率≈0；出海可用（华为/小米式做法） | 放弃"意译"，海外用户读不出含义 |
| **S2** | **意译改用生造/复合词** | 加缀或拼接：`Attunely`、`Beatwise`、`Tempo…` | 保留意译感，且可商标化 | 略"做作"；仍需逐个检索 |
| **S3** | **意译改用低频实词**（推荐） | 走 `Kairos` / `Linger` 那一类低频词，避开健身高频词表 | **保留用户的"意译"偏好**，改动最小 | 需要重新按"英文可注册性"反选中文 |
| **S4** | **中英文不同源** | 中文走古诗，英文另取一个低碰撞词，两者不互译 | 自由度最大，成功率最高 | 丢掉"一名双解"的雅趣 |
| **S5** | **中文改用三/四字词组** | 取自冷门篇目的整句片段 | 中文侧可拿到空位 | 名字变长，口语传播略难 |

### 关键方法论调整：把顺序反过来

V1→V2 都是 **中文 → 英文**（先定古诗里的词，再意译）。这条路已经证明会连续撞墙。

建议改成 **英文 → 中文**：

1. 先在健身/节律赛道里**筛出一批"还没被占"的英文词**（这是可穷举的：查 App Store / Google Play 重名 + 域名）；
2. 再为筛出的英文词**去找一句能与之对应的古诗**。

这样中文侧的"古诗"约束仍然满足，但**可注册性从第一步就被锁定**，不会再出现"想得漂亮、一查全没了"的情况。

## 4. 待补的正式检索（本次未做，不替代法律意见）

1. **中国商标网**：候选中文名的第 **9 类**（计算机软件）、**41 类**（在线健身/培训）、**42 类**（软件开发）在 45 类之外的空位——本次只查到 `应律` 的 45 类已注册，其余类目未逐类核。
2. **App Store / Google Play / Microsoft Store** 重名（本次仅抽样命中，未穷举）。
3. **域名**：`.com` / `.app` / `.cn` 可用性。
4. **发音复述测试**：6 个名字给 5~10 位**目标用户（男女各半、实际在健身）**念一遍并隔天复述。

---

## 5. 建议

**先拍 S1～S5 的路线，再选名字。**

理由：本轮结果说明"名字还没定"不是关键，**"用什么方法定名字"才是关键**。路线不换，下一批候选大概率还会是同样的结局。

若只选一条：**S3（意译改用低频实词）+ 反向顺序（英文→中文）**——既守住了"取自古诗词、英文意译"的原始偏好，又把成功率从源头提上去。
