# 最终三选 · 可用性评审（有常 / 潮有信 / 来复）

> 时间：2026-09-11
> 范围：用户圈定的三个候选 —— **有常 · 潮有信 · 来复**
> 核查方式：联网检索商标详情库（阿里云商标 / 企查查 / 启信宝 / 标库网）
> 性质：**初筛，不构成法律意见**。正式判定须在中国商标网（sbj.cnipa.gov.cn）逐类核验。

## 1. 来复：被第 9 类挡住 ❌

**这是本轮唯一一个明确的否决项。**

| 项 | 内容 |
|---|---|
| 商标 | **来复** |
| 注册号 | **90415176** |
| 类别 | **第 09 类**（科学仪器） |
| 类似群 | **0901**（含 *可下载的手机应用软件*）、0902、0903、0904、0905、0910、0911、0913、0914 |
| 申请人 | **河北来复医药科技有限公司** |
| 申请日 | 2026-03-06 |
| 状态 | **已初审** —— 初审公告日 **2026-08-27**（第 1997 期） |

**为什么这是致命的**：0901 群的"可下载的手机应用软件"就是本产品的核心类目。且该商标**已于 2026-08-27 进入初审公告**——按流程，公告期 3 个月（至约 2026-11-27）无异议即核准注册。

更值得警惕的是申请人是**医药科技公司**——与我们同处健康领域，撞车的可能性不是理论上的。

另有一件：「来复」第 45 类已注册（注册号 16976801，**广东来复律师事务所**，专用权 2016-07-21～**2026-07-20**，刚届满）。

**结论：来复不能用作 App 名。** 概念（《周易》"七日来复"＝循环＋恢复，正对 work/rest）确实好，但位置已经没了。

## 2. 潮有信：可继续 ⚠️

| 项 | 内容 |
|---|---|
| 商标 | **潮有信** |
| 注册号 | **76654558** |
| 类别 | **第 32 类**（啤酒饮料） |
| 类似群 | 3201（啤酒）、3202（含 *运动饮料*、果汁、植物饮料、气泡水等） |
| 申请人 | 董永华 |
| 专用权 | 2024-08-21 ～ 2034-08-20 |
| **第 9 / 41 / 42 类** | **未命中占用** |

**需注意的三点：**

1. **第 32 类已被注册，且核定商品含"运动饮料"** —— 与健身场景是语义邻居。虽然类别不冲突（饮料 vs 软件），但**市面上会出现一个同名运动饮料品牌**，品牌混淆风险实际存在。
2. 两家同名公司：**浙江潮有信投资管理有限公司**、**南昌智潮有信网络科技有限公司**（经营范围含"软件开发""动漫游戏开发"）——后者是软件同行。
3. 原诗《江南曲》是闺怨（"早知潮有信，嫁与弄潮儿"），做副标题时需另立语境。

**结论：9/41/42 类干净，可以用。** 但若走品牌化路线，建议提前规划与 32 类饮料品牌的区分（如加副标题、差异化视觉）。

## 3. 有常：三个里最干净 ✅

**未见「有常」本体在第 9 / 41 / 42 类的占用。** 现有的都是"家族商标"，不构成直接阻挡：

| 商标 | 类别 | 状态 | 说明 |
|---|---|---|---|
| **每日有常** | 41 类 | **已注销**（2026-04-13 未续展注销公告，第 1979 期） | 原注册号 12821242，申请人 常自有，专用权 2014-12-14～2024-12-13，含*培训*、*体育场设施出租* |
| **林有常** | 35 类 | 已注册（81641627，2024-10-29） | 广告/商业管理 |
| **有常居** | 44 类 | 待审中（90390850，杭州新视橙健康科技） | 医疗/按摩/美容，已于 2026-05-28 驳回通知 |
| **有常居** | 25 类 | 已销亡（76537883，杭州陶宛堂健康科技） | 服装/瑜伽袜 |

**两点观察：**

1. **「每日有常」的 41 类商标刚在 2026-04-13 因未续展被注销** —— 说明「有常」这一族在 41 类（教育／文体）**目前有空位**。
2. 但也要正视：**「有常」作为独立商标的显著性偏弱**（"有常"是常用文言词，含义偏向描述性的"有规律"）。这既是它能空着的原因，也是注册商标时可能被审查员质疑显著性的原因。**建议连同 9/41/42 三类一并申请，并准备使用证据。**

## 4. 替换建议（顶替"来复"的位置）

「来复」占的坑是**循环／恢复（work-rest 交替）**这一层。同层的名字已被扫得差不多：

| 同层候选 | 状态 |
|---|---|
| **周行**（《老子》「周行而不殆」） | ❌ **第 9 类已注册**：注册号 42391137（章坤，2020-08-21～2030-08-20），0901 含*可下载的手机应用软件* |
| **盈科**（《孟子》「盈科而后进」） | ⚠️ 「盈科」是著名律所，慎 |
| **往复**（《周易》「无往不复」） | ⬜ 未查，但属高频常用词，显著性弱 |

**所以我的建议是跨层替换**，从呼吸层取 —— 因为"呼吸"在概念上已经隐含了 work/rest 的交替：

### 首推替换：数息

| 项 | 内容 |
|---|---|
| 出处 | 佛家「数息观」（五停心观之一）—— 一边呼吸一边计数 |
| 覆盖 | **规划**（数着一组一组）＋**掌控**（数着一息一息）＋ 隐含 rest（息＝休息） |
| 第 9 类核查 | **未见「数息」本体占用**；仅存在 **北京数息数据科技有限公司**（其商标为 `IPROGNOSIS`，第 9 类，注册号 29807067，非"数息"二字） |
| 气质 | 中性、无军事、无性别指向；比「来复」更直观 |
| 风险 | 佛家色彩偏静态冥想，需要靠产品语言拉回"训练"语境 |

### 备选替换

- **涓涓**（《孔子家语》「涓涓不壅，终为江河」）—— 讲"坚持"，最女性友好；⬜ 待查
- **有恒**（《论语》「人而无恒，不可以作巫医」）—— "坚持"最直白；⬜ 待查。**但注意与「有常」同族，若保留有常则此名不宜并列**
- **往复** —— 同层最贴近原意；⬜ 待查，显著性偏弱

**若你认可，最终三选即：`有常` · `潮有信` · `数息`。**

## 5. 英文名（低频优先；英文侧是本项目最大的历史雷区）

前情：`Attune` / `Stride` / `Rise` / `Kindred` / `Ripple` / `Cycle` / `Abide`(待查) 一类"意译得漂亮"的高频英文词，在健康健身赛道已全被占。

| 中文 | 英文候选 | 说明 | 状态 |
|---|---|---|---|
| **有常** | `Constancy` | "恒常、有常"，低频，非健身高频词 | ⬜ 待查 |
| | `Abide` | 古语感，含"持守"义 | ⚠️ 疑似已有同名冥想类 App，需查 |
| **潮有信** | `Truetide` | 生造（tru(e) + tide），意为"守约的潮" | ⬜ 待查（生造词碰撞率低） |
| **数息** | `Tally` | 计数／记录——**同时对上"数息"与"留痕"** | ⬜ 待查 |
| | `Reckon` | 计数、结算，低频 | ⬜ 待查 |
