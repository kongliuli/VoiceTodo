## 0. 先看一件有意思的事：你给的三个词，古代中国是同一个字

**规划 · 掌控 · 沟通**——在现代是三个能力，在古代军营里是**同一套东西**，那个东西叫**鼓**。

| 你要的能力 | 古代怎么做 | 载体 |
|---|---|---|
| **规划** | 分轮次、分批次投入兵力 | 「一鼓作气，**再**而衰，**三**而竭」——鼓声即轮次 |
| **掌控** | 鸣鼓进军、鸣金收兵 | 鼓是命令本身：*击鼓进军，鸣金收兵* |
| **沟通** | 以声传令，全营同时听见 | 鼓角之声替代口令 |

所以**「鼓」一个字符就覆盖了你说的三件事**；而且它天然是**分轮次**的——「一鼓作气，再而衰，三而竭」讲的是**按轮次分配体力**，这**就是间歇训练的原理**，比现代健身理论早了两千多年。

这条线索是我这一轮的主线：**不要去找「健身」「计时」的字面词，去找「以声号令」的意象。**

## 2. 逐项说明

### A · 鼓角 / Clarion ★推荐

- **原句**：杜甫《阁夜》「五更**鼓角**声悲壮，三峡星河影动摇。」
- **为什么是它**：`鼓角` 在古代军中**同时承担两件事**——**报时**（报更）和**传令**（发号施令）。而本 App 恰好也在做这两件事：**计时**（阶段/轮次）+ **用语音跟你对话**（提示、发令、回话）。名字直接就是产品本身。
- **三词覆盖**：鼓点分轮次（规划）· 击鼓即发令（掌控）· 角声传达到全营（沟通）。
- **占用**：已检索，未发现同名 App（返回结果均为不相关的音乐/音效类应用）。
- **英文意译 `Clarion`**：指的是**清亮高亢的号角声**，英语里 `a clarion call` 就是「号召」。含义对得上 角 的部分。
- **要诚实说明的两点**：
  1. 出处那句是「声**悲壮**」——底色偏雄浑悲慨（健身语境里其实不算违和，但要知道它是这个气质）。
  2. `鼓角` 对现代读者略生僻，"角"容易被读成 jiǎo（角落）而非军中的号角。需要靠商店副标题托底。

### B · 击鼓 / Drumroll

- **原句**：《诗经·邶风·击鼓》「**击鼓其镗，踊跃用兵**。」（镗 tāng，鼓声）
- **为什么强**：《诗经》是最正统的「古诗词」源头；而且这一句**本身就是画面**——鼓声镗镗一响，人跃跃欲试。产品要的就是这个瞬间。
- **三词覆盖**：`用兵` = 调度部署（规划）· 击鼓进军（掌控）· 鼓声传令（沟通）。
- **优势**：人人能懂，两字动词，能量感最强，是三选一里**最容易被记住**的。
- **风险**：「击鼓传花」这一成语游戏是唯一常见联想（不构成冲突，但会带一点轻松感，与"严肃训练工具"略有偏差）。
- **英文 `Drumroll`**：字面意译（鼓的连击）；英语里 `drumroll please` 有"宣布"的意味，与"发令"相通。

### C · 点兵 / Muster

- **原句**：辛弃疾《破阵子·为陈同甫赋壮词以寄之》「八百里分麾下炙，五十弦翻塞外声，**沙场秋点兵**。」
- **为什么合适**：`点兵` = 检阅、清点、排布。**本产品的核心操作恰好是"用一句话把组数和时长排好"**——这就是点兵。而且是三词里**唯一把「规划」放在最前面**的候选。
- **英文 `Muster`**：英语里同时是「集合点验部队」和「鼓起（勇气/力气）」（*muster up*），两个意思都对得上。
- **风险**：偏军事；对「待办」这一半产品完全没有覆盖。

### D · 踏歌 / Stride

- **原句**：李白《赠汪伦》「李白乘舟将欲行，忽闻岸上**踏歌**声。」
- **为什么合适**：`踏歌` = 以脚踏地为节拍而歌——**踩着拍子动**。这是"沟通"最优雅的一个意象：它给你节拍，你跟着动。
- **风险**：`踏歌` 在现代语境里主要因《赠汪伦》而带**送别**色彩；且对「规划 / 掌控」几乎无覆盖。

### E · 更漏 / Ticking

- **原句**：温庭筠《更漏子》「柳丝长，春雨细，花外**漏声**迢递。」（`更漏` 亦为词牌名）
- **为什么合适**：`漏` 是**漏刻**，古代计时器。关键点在于：**它靠滴水的声音来报时**——一个用"声音"计量"时间"的装置，与"用语音播报阶段"的 App 完全同构。
- **风险**：`漏` 在现代汉语里主要是"泄漏 / 漏掉"（负面）；`更` 有 gēng / gèng 两读，会念错。

### F · 一鼓 / Impetus

- **原句**：《左传·庄公十年》曹刿论战「**一鼓作气**，再而衰，三而竭。」
- **为什么合适**：这是六项里**最直接讲"间歇"的**——它讲的就是按轮次分配体力，且明确点出"第二轮会衰减"这一训练学事实。
- **风险**：① 出处是《左传》（先秦散文），**严格说不是"诗词"**，与前五项性质不同，需你确认是否接受；② `再而衰` 的负面含义会被带进来，可能暗示"第二轮就不行了"。

## 3. 推荐

**首选：A · 鼓角 / Clarion**

它赢在**结构**而不是赢在好听：`鼓角` 是古代军中唯一一件**同时干"计时"和"传令"两件事**的东西，而这正好是产品的两条腿。你给的三个词（规划/掌控/沟通）在它身上不需要解释就能对上。

**按你的侧重挑：**

| 你更看重 | 选它 | 英文 |
|---|---|---|
| **沟通 + 计时**（声音与你对话） | 鼓角 | Clarion |
| **掌控 + 能量感**（最直白、最热血） | 击鼓 | Drumroll |
| **规划**（一句话排好训练） | 点兵 | Muster |

**次选：B · 击鼓**——如果"鼓角"的生僻度让你犹豫，`击鼓` 是同样覆盖三词、但**所有人都能立刻听懂**的版本，代价是稍微少了点独特性。

## 4. 必须说清的一个取舍

这一轮的所有候选都建立在一个前提上：**把"健身 / 间歇"当成产品的第一身份**。

代价是：**它们几乎不覆盖「待办」那一半**。`鼓角`、`击鼓`、`点兵` 都是军事-训练意象，用户不会想到"这也能语音记待办"。而 `知时节`（通用方向提案）走的是另一条路——它覆盖"待办 + 提醒"，但对健身几乎没有指向。

所以真正要拍的板不是名字，而是：

| 问题 | 影响 |
|---|---|
| 产品对外主打**健身训练**，还是**免提待办**？ | 决定用这一份还是上一份 |
| 如果两者都要，哪个当"主角"？ | 名字跟主角走，另一个靠副标题补 |

我的判断：`master` 里分析出的**蓝海是健身/免提定时器**（`market-and-competitors.md` 结论：语音待办是红海）。若认同这一点，**名字应该向健身倾斜**——即这一份的方向。
