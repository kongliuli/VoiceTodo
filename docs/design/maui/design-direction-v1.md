# VoiceTodo 产品设计母版 V1

日期：2026-09-11。状态：已生成、待用户审定；不是用户已批准稿。来源为当前联网调研与产品设计判断，现有代码仅作为实现差距参考。

## 产品目标

帮助用户在手忙、想到即记、需要按时行动的场景中，完成「捕捉 → 理解与纠正 → 安排 → 提醒 → 行动」。首页回答下一步做什么；语音是全局输入方式。优先个人待办、日常计时、健身间歇，不引入团队协作或社交。

## 调研依据与设计转化

| 官方来源 | 本次采用的事实 | 本产品设计判断 |
|---|---|---|
| [Things](https://culturedcode.com/things/features/) | Today 聚合日常事项，并提供 This Evening 分组 | 以「今天」为首页；按行动时间整理任务，完成项收起 |
| [Structured 入门](https://help.structured.app/en/articles/380546) | 日程时间线与没有指定时间的 Inbox 分开 | 增加「待安排」，没有时间的语音记录不强行填入时间线 |
| [Todoist](https://www.todoist.com/features) | 自然语言 Quick Add 支持快速捕捉和安排任务 | 语音与文字共用捕捉流程，识别出的时间和重复规则可纠正 |
| [Seconds](https://www.intervaltimer.com/app) | 计时强调大触控目标、语音提示和训练时可读性 | 首页提供紧凑运行卡；计时详情另设大字操作视图 |
| [Android 无障碍](https://support.google.com/accessibility/android/answer/7101858?hl=en) | 建议触控目标至少 48×48dp | 图标视觉尺寸与实际触控范围分开定义 |

这些来源用于研究信息组织和操作原则，不复制其品牌、图标或整套界面。配色、组合方式和以下流程是本项目提案，不是来源中的结论。

## 信息架构

底部主导航：今天 / 清单 / 计时。设置从页面顶部进入。语音是全局操作，不占导航目的地。

| 页面或交互层 | 用户目标 | 必须设计的状态 |
|---|---|---|
| 今天（本次母版） | 查看即将行动的事项、运行计时器、快速记录 | 正常、空、加载、错误、有/无运行计时器 |
| 清单 | 浏览待安排、未来、已完成事项，搜索 | 有内容、空、筛选、搜索无结果 |
| 任务详情与编辑 | 修改标题、日期、时间、重复、提醒、备注 | 新建、编辑、输入错误、删除确认 |
| 语音捕捉面板 | 录入并确认理解结果 | 权限说明、正在听、处理中、可编辑结果、失败、取消 |
| 文字捕捉面板 | 不方便说话时快速记录 | 输入、识别字段、确认保存 |
| 计时列表 | 创建日常倒计时或选择间歇模板 | 空、预设、多个计时器、运行摘要 |
| 计时编辑 | 定义名称、时长或工作/休息/轮数 | 普通、间歇、校验错误 |
| 计时运行 | 远距离查看剩余时间、暂停或结束 | 准备、运行、休息、暂停、完成 |
| 提醒响应 | 完成或延后事项 | 到期、延后选择、已完成；系统通知与应用内呈现分别设计 |
| 设置 | 管理提醒、语言、声音、外观及隐私 | 正常、权限不足、模型不可用；技术诊断放次级入口 |
| 首次使用 | 理解语音与提醒价值，按需授权 | 欢迎、首次录音授权、首次提醒授权、拒绝后的替代操作 |

表中是目标设计范围，不表示这些能力已经实现。页面和弹层数量由完整流程决定，不沿用旧版 13 张图预算。

## 母版布局与视觉规范

- 文件：`today-master-v1.png`。单屏、正视、无设备壳。图中数据均为演示数据。
- 手机逻辑基准：390×844；外边距 20；间距 8/12/16/24；卡片圆角 8。
- 背景 #F7F8FA；表面 #FFFFFF；主文字 #182230；次文字 #586575；边线 #E3E7EE。
- 主操作 #315BE8；选中背景 #EDF2FF；计时状态 #9B5E10 搭配浅琥珀底。
- 页面标题 30sp；正文 16sp；辅助文字 13sp；计时数字使用等宽数字。实际实现尊重系统字体缩放。
- 字体用系统中文无衬线；图标统一线性风格，不将图片中的图标裁切进界面。
- 布局：日期与标题 → 今日摘要 → 运行计时器 → 今日安排 → 已完成折叠 → 待安排 → 固定语音/文字入口 → 主导航。
- 图中的字体大小、浅渐变、圆角和系统栏不是精确实现参数；以上规范是开发依据。系统状态栏和手势区由平台处理。
- 语音主按钮高 56dp；其余交互目标至少 48×48dp。完成圆圈可以小，但触控区不能小。
- 小屏或大字体下，中间内容滚动；固定操作区及导航不遮挡最后一项。计时标题和任务标题允许换行。
- Windows 使用同一信息架构与颜色语义，改为侧边导航和列表/详情双栏，语音入口常驻；不直接拉伸手机图片。

## 交互契约

1. 点击语音入口才开始拾音；录音与处理中有不同状态，取消不保存。待机不展示误导性的拾音动画。
2. 识别结果显示为可编辑任务草稿，明确标题、时间、重复和计时类型；歧义须在保存前解决。确认保存后提供撤销。
3. 文字输入与语音结果使用同一编辑和校验规则。没有时间的记录进入待安排。
4. 点击任务主体进入详情；完成区域单独响应。删除置于详情或菜单，不在每行常驻红色删除按钮。
5. 计时卡显示当前真实剩余时间，进度按经过时长计算；暂停按钮独立响应，卡片主体进入运行详情。
6. 多个运行计时器：首页显示最早结束项和其余数量入口；计时页查看全部。没有运行项则移除卡片，不保留空壳。
7. 「查看全部」进入清单的今天筛选；「待安排」进入对应清单；已完成项默认折叠。
8. 到期提醒提供完成/延后；系统能力不足时说明实际状态，不承诺必达或突破勿扰。
9. 没有实际验证之前，不在产品界面声称完全离线、录音永不上传或提醒可靠性保证。
