# 隐私说明（VoiceTodo 1.0）

> 适用范围：本仓库构建的 VoiceTodo App（Android / Windows）。最后更新：2026-09-14。
> 本文描述的是**当前版本的实际行为**，不是宣传口径；与代码不一致之处一律以代码为准并在此修正。

## 一句话

语音识别与数据存储**全部在设备本地完成**。App 不发起任何网络请求，不上传、不联网、无账号、无埋点、无广告。

---

## 1. 你的数据放在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 待办 / 计时 / 训练记录 | `<应用私有目录>/voicetodo.json` | 单文件 JSON；写入走临时文件 + 原子替换，避免写坏 |
| 运行中的计时快照 | `<应用私有目录>/running-timer.json` | 阶段变更即落盘，用于崩溃 / 重启后恢复 |
| 损坏库的备份副本 | `<应用私有目录>/voicetodo.json.corrupt-<时间戳>` | 主库解析失败时**自动保留副本**，绝不静默清空为「空库」 |
| 语音模型 | `<应用私有目录>/Models/<模型相对路径>` | 首次使用时从安装包解压到本机 |
| **录音文件（WAV）** | `<应用私有目录>/captures/capture-<时间戳>.wav` | ⚠️ 见第 4 节 |
| 设置项 | 系统 Preferences（Android 为 `SharedPreferences`） | 语言、铃声、延后、场景、Nag 等 |

「应用私有目录」的实际映射：

- **Android**：`/data/data/com.voicetodo.app/files/` —— 其他 App 无法读取，卸载即删除；
- **Windows**：`%LOCALAPPDATA%\VoiceTodo\`。

## 2. 权限用途

| 权限 | 用途 | 必需性 |
|---|---|---|
| `RECORD_AUDIO` | 录音并做端侧语音识别 | 语音功能必需；可拒绝，改用文字输入 |
| `POST_NOTIFICATIONS`（Android 13+） | 弹出待办提醒 | 提醒功能必需。Android 13+ 在引导完成或首次创建带提醒待办时**运行时申请**；若被拒绝，提醒不会弹出，应用在保存时如实提示「通知权限未开启」 |
| `VIBRATE` | 提醒震动 | 可选 |
| `FOREGROUND_SERVICE`<br>`FOREGROUND_SERVICE_SPECIAL_USE` | 训练计时期间保活并显示常驻通知 | 计时保活必需 |
| `INTERNET` | **当前版本未使用** | 全仓无网络代码；该声明是给将来「模型下载」预留的。介意可直接删除，见下 |

> **已知不一致（如实记录）**：`INTERNET` 权限已声明但当前版本不联网。
> 若无需该预留，可从 `src/VoiceTodo.Maui/Platforms/Android/AndroidManifest.xml` 删除对应 `<uses-permission>` 行。

## 3. 语音数据怎么处理

1. 录音以 16 kHz 单声道 PCM 写入 WAV 文件；
2. 交由随包的 `whisper-tiny` 模型在**本机**识别（whisper.cpp）；
3. 识别文本只用于在本地生成待办 / 训练计划草稿，可当场修改；
4. **音频与文本都不会离开设备** —— 全仓无 `HttpClient` / 无上传 / 无遥测。

## 4. 录音文件保留（保留 7 天后自动清理）

- 说完一句（正常结束或超时结束）后，WAV 文件**会保留**在 `<应用私有目录>/captures/`；
- 只有「取消本句」会丢弃文件；
- **保留 7 天后自动清理**：App 每次启动（`App.xaml.cs` 触发，fire-and-forget，不阻塞启动）清理 `captures/` 下**修改时间早于 7 天**的 `.wav`；
  判定以文件修改时间为准，文件名 `capture-yyyyMMdd-HHmmss.wav` 作为兜底；清理失败静默忽略，不影响启动。

## 5. 你的控制权

| 想做的事 | 怎么做 |
|---|---|
| 删除全部数据 | Android：卸载 App；Windows：删除 `%LOCALAPPDATA%\VoiceTodo` |
| 只清录音 | 删除应用私有目录下的 `captures/` 目录 |
| 不想用麦克风 | 拒绝录音权限，改用「打字添加」入口（与语音共用同一条解析管线） |
| 不想收提醒 | 关闭通知权限，或在系统通知设置中屏蔽本应用 |

## 6. 明确不做的事

- 不做账号 / 登录 / 云同步 / 多端同步；
- 不做埋点、崩溃上报、广告 SDK；
- 不读取通讯录、位置、相册、剪贴板、设备标识；
- 不向任何第三方传输或共享数据。
